(Syllabus)

This student-built website explores ideation, design, graphics and user interfaces using software and coding languages through Harris Rosenblum’s Coding GPH/INTER, RISD 2026. Projects cover the history, theory and implementation of graphics and user interfaces from the beginning(01) to contemporary computing to present day. Graphic experiments start with OpenGL(02), image processing(03), and 3D pipelines(04)(05), and move to standard web based GUIs(06), UX design(07) principles, games(08), and Human Interface Devices(09) as ways of understanding interfaces. The final project(10) explores applications for generating graphics using a custom build interface.
